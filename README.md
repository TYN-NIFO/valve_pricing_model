# Valve Pricing ML Model

Machine learning project for estimating industrial valve prices from valve specifications. The project includes a FastAPI backend, a CatBoost regression model, OCR-based PDF extraction, PostgreSQL persistence, and a React/Vite frontend dashboard.

## Project Structure

```text
.
├── Backend/
│   ├── api.py                         # FastAPI application
│   ├── db.py                          # PostgreSQL connection settings
│   ├── predict.py                     # Model loading and prediction helper
│   ├── train_model.py                 # CatBoost training script
│   ├── requirements.txt               # Python dependencies
│   ├── valve_pricing_dataset_2000.csv # Training dataset
│   └── models/                        # Generated model files
├── Frontend1/
│   ├── src/                           # React app source
│   ├── package.json                   # Frontend scripts and dependencies
│   └── vite.config.js                 # Vite dev server and API proxy
├── valvePricing.py
├── valvePricingV1.py
└── .gitignore
```

## Features

- Predicts valve price from manual valve inputs.
- Trains a CatBoost regression model using the included CSV dataset.
- Supports RFQ PDF upload and field extraction using PaddleOCR.
- Stores prediction history in PostgreSQL.
- Provides a React dashboard to create predictions and inspect saved results.

## Backend Setup

From the project root:

```powershell
cd Backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Train the model if `Backend/models/valve_model.cbm` is missing:

```powershell
python train_model.py
```

Run the API:

```powershell
uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

The API will be available at:

```text
http://127.0.0.1:8000
```

FastAPI docs:

```text
http://127.0.0.1:8000/docs
```

## Database

The backend currently connects to PostgreSQL using settings in `Backend/db.py`:

```text
host: localhost
port: 5432
dbname: valve_ml_db
user: postgres
```

Create the database and ensure it contains a `valve_price_predictions` table matching the fields inserted in `Backend/api.py`.

For local development, update `Backend/db.py` with your own PostgreSQL username and password before running the API.

## Frontend Setup

In a separate terminal:

```powershell
cd Frontend1
npm install
npm run dev
```

The frontend runs at:

```text
http://localhost:5173
```

During development, Vite proxies `/api` requests to the FastAPI backend at `http://127.0.0.1:8000`.

## Main API Endpoints

```text
POST /predict
POST /predict-from-pdf
GET  /predictions
GET  /predictions/{valve_id}
```

## Notes

- `Backend/models/` is generated by training and is ignored by Git.
- `Frontend1/node_modules/` is ignored by Git and should be recreated with `npm install`.
- PDF prediction requires OCR dependencies to be installed successfully. If PaddleOCR or PDF rendering dependencies are unavailable, manual prediction still works.
